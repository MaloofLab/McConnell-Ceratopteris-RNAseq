From Andrew Plackett:

Breakdown of the sheets:
Arabidopsis gene data: lists of Arabidopsis genes from the various reproductive datasets I culled- each column is a dataset, as labelled. The first column is the vegetative-specific control, and all others were filtered to remove the few genes that overlapped (because no-one quite agrees what 'vegetative specific' is, so I had to take the control on trust)  The source piublication is listed for each (and where possible the source file/location within the publication). Where I had to make judgements about what genes from each dataset to include I have listed those too.

Orthofinder orthogroups: created using the Orthofinder program comparing multiple genomes across the land plants (please see the preprint materials and methods for the full list).  Each row represents all related genes from across those genomes, more-or-less at the gene family. You may well be more knowledgeable about this than I, but just in case I would refer to genes from different species within the same orthogroup as 'homologs'

Orthofinder orthologs Cr v At: a more stringent set of relationships output from the Orthofinder analysis, restricted to identifying orthologs between Ceratopteris genes and Arabidopsis genes across the whole Ceratopteris genome. The parent orthogroup is also listed on the far left.  This is what I used to 'translate' Ceratopteris genes into their most direct Arabidopsis relatives (i.e their orthologs, genes descended from the same ancestral gene within the genome). It's not always a one-to-one relationship, and not all Ceratopteris genes have Arabidopsis orthologs (and not all Arabidopsis genes have a Ceratopteris ortholog).  Hopefully you can use this as the basis for assigning relationships between your candidate Ceratopteris genes and Arabidopsis.

Ceratopteris annotation: all the annotation data I was able to glean. Some of this comes from a BLAST search done by the company Novogene when they did our next generation sequencing (columns 'Cr_defline' and 'Cr_genedescription). However, not every Cr gene had annotation based on this, so to try to plug the gaps we looked to the orthologs in the other main land plant models. To do this I appended the annotations from any orthologous genes in Arabidopsis, rice, Selaginella, Physcomitrium, Marchantia, on the same row as the corresponding Cr gene.  This annotation data came from their respective genomes and each is in its own column.  It hasn't filled them all in, but on a surprising number of occasions it has provided an annotation of some sort, even if not Arabidopsis.

Ceratopteris inherited GOterms: to make GOterm enrichment easier, a datet restricted to the GO terms for each Ceratopteris gene extracted from the annotation sheet, including GO terms taken from the orthologous genes from model species.  It covers the whole genome, including Cr genes that had no GO terms inherited.


Limitations:
So the big limitation is that the Orthofinder analysis was based on a fixed, limited number of genomes and the chpoice of genomes will influence the algorithm.  If it was rerun with  genomes of different species (or updated genomes of the same species) you might now well obtain different relationships between the genes.  This was only created a couple of years ago but as far as I can tell the genomes involved haven't been updated, and we aimed for a wide representative spread from across the land plants so my hope is that it is reasonably representative and stable, and good for at least one more use before we have to rerun the relationships.
I hope this'll be useful! :)
